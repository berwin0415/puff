# 验收报告与证据索引

记录候选初筛、同题详细验证和恢复、多用户、成本等专项结果。

主要内容：

- `recommendation.md / comparison.md`：条件化建议与能力比较。
- [下一轮主场景实验设计](next-round-main-scenario-design.md)：以当前报告为基线的主场景契约、接入消耗与跳过规则。
- [下一轮冻结计划](next-round-plan.json)：基线、候选版本、任务集、token 预算与阶段。
- [下一轮运行记录 001](next-round-run-001.md)：token 代理实现、真实 smoke 与下一步。
- [M0/M1/E1 完成记录](next-round-m0-m1-close.md)：冻结范围、M1 校准、E1 结果。
- [剩余任务与执行状态](next-round-remaining-tasks.md)：E2–E6 任务板、状态记录区、完成标准。
- `各候选报告`：候选入口、实测结果、能力来源及局限。
- `专项设计与执行记录`：实验接线、固定材料、失败原因和外部原件路径。
- `各类 JSON / SHA256 清单`：安全统计摘要和冻结材料清单。
- [中文维护说明](chinese-maintenance.md)：当前代码文案、目录说明及历史材料边界。
