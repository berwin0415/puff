# 验收报告与证据索引

记录候选初筛、同题详细验证和恢复、多用户、成本等专项结果。

主要内容：

- `recommendation.md / comparison.md`：条件化建议与能力比较。
- `各候选报告`：候选入口、实测结果、能力来源及局限。
- `专项设计与执行记录`：实验接线、固定材料、失败原因和外部原件路径。
- `各类 JSON / SHA256 清单`：安全统计摘要和冻结材料清单。
- [中文维护说明](chinese-maintenance.md)：当前代码文案、目录说明及历史材料边界。

唯一任务进度见根目录 IMPLEMENTATION_PLAN.md；已完成调研不代表所有能力通过。历史证据及冻结哈希不因当前注释或文案修改而重写。
