## v0.1 验证范围

当前 Codex 已加载本地产物并识别 onboarding 和两个 skill。Codex 会话使用隔离的本地配置在 puff 工作区通过了安装引导、绑定、只读试跑和样例任务读取。核心和插件测试覆盖工作区、授权、窗口、名额、暂停及交付未知时的处理。

原生计划的实际唤醒与活动状态、宿主取消，以及实际绑定能力的交付、评审和通知继续按宿主和外部工具的实测结果更新。
