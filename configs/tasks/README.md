# 调研任务定义

固定普通工具、浏览器、规则、暂停恢复、故障、多用户和实例成本任务。

主要内容：

- `tools.yaml / browser.yaml`：同口径工具和网页业务输入。
- `business-extension.yaml / control-policy.yaml`：业务扩展及执行规则。
- `pause-resume.yaml / fault-recovery.yaml`：恢复专项及故障窗口。
- `scope.yaml / instance-cost.yaml / runtime.yaml`：身份边界、资源成本和运行基础。

修改输入、提示、预算或判定条件时，创建新实验材料并保留旧证据；不得用新规则改写历史结果。
