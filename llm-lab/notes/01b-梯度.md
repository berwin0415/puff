# 第 1 步补充：梯度是什么

## 一句话

**梯度 = "每个参数各有一个斜率"的打包。** 它不告诉你答案，它告诉你：每个旋钮往哪边拧、拧一点点会怎样。

这是整条学习线上唯一一个"不理解就寸步难行"的数学概念，所以单独拿出来讲。

## 怎么读这篇

**标记约定**：出现 `（→ 第 N 步）` 表示那个概念在后面那一步才正式讲解，这里只需要知道名字。

**范围**：本文只负责讲清楚"梯度是什么"。它**怎么被用起来**属于后面的步骤，本文只给最小的词汇表，不展开。

### 先给两个词的临时定义

讲梯度绕不开两个词，它们的正式讲解都在后面。这里先给最小含义，够读本文就行：

| 词 | 本文的含义 | 正式讲解 |
| --- | --- | --- |
| **损失** | 一个数字，衡量"现在有多糟"。我们想让它变小 | 第 3 步 |
| **学习率** | 沿着梯度反方向走的时候，一步迈多大 | 第 8 步 |

两个词都相当自解释：一个是"我们不希望它变大的那个数"，一个是"每步走多远"。读到它们卡住时，回这张表即可。

## 从斜率开始：一个数进去，一个数出来

先看一个最简单的函数：

```
f(w) = (w - 3)²        它的谷底在 w = 3
```

在 `w = 0` 处，`f = 9`。这一点的**斜率**是多少？求导得 `2(w - 3)`，代入得 **-6**。

这个 -6 的含义是：**把 w 增加一点点，f 大约减少 6 倍那么多。** 注意是"大约"——斜率本身会随 w 变化，只在一小步内才准确。

于是它立刻给出了行动方向：既然增加 w 会让 f 变小，那就增加 w。反过来，如果斜率是正的，就该减小 w。

在 `w = 3` 处斜率是 0——已经到底了，没得走了。

这里有个容易混的点：**斜率不是函数值，是变化率。** `f(0) = 9` 是"现在多高"，斜率 `-6` 是"往哪边走、走多快"。

## 从斜率到梯度：很多个数进去，一个数出来

真实的损失不是"一个参数进去"，而是**几百万个参数共同决定一个数**：

```
损失 = f(w₁, w₂, w₃, ..., w₁₀₀₀₀₀₀)
```

梯度就是把"斜率"这个概念对**每一个参数各算一次**，然后打包成一个张量。

于是得到两条几乎不用记就成立的结论：

- **参数的形状是什么，梯度的形状就是什么。** 每个参数都需要自己的一份"往哪边调"。
- **梯度的每个元素回答同一个问题**："只把这个参数调大一点点，损失会怎么变？"

数学书里管这个过程叫"偏导数"——"偏"的意思就是"一次只看一个变量，其他的当作不动"。名字听着吓人，做的事情就是上一节那件事，只是重复几百万遍。

顺带说明为什么不能一次动一个参数去试：参数有 100 万个，每个都试两次就要跑 200 万次前向。梯度的高明之处在于**一次反向传播就把所有参数的方向全算出来了**。

## 实测：手算和 autograd 对得上

`scripts/step01_gradient_descent.py` 的输出（这里只看第一部分，后面的部分在后面几步才需要）：

```
f(w) = (w - 3)^2,  最小值在 w = 3
     w     f(w)      手算 2(w-3)   autograd 含义
   0.0      9.0           -6.0       -6.0 w 增大 1，f 大约增加 -6.0
   2.0      1.0           -2.0       -2.0 w 增大 1，f 大约增加 -2.0
   3.0      0.0            0.0        0.0 在最小值上，斜率为 0
   5.0      4.0            4.0        4.0 w 增大 1，f 大约增加 +4.0
```

**手算和 autograd 给出的梯度完全一致。** autograd 没做什么魔法，它做的就是链式法则——把斜率一层层乘下去。（→ 第 6 步把梯度送进注意力层时链条会变长，但道理不变）

这张表还说明了斜率的两个含义：**符号给方向**（正的就该调小，负的就该调大），**大小给幅度**（离谷底越远，斜率绝对值越大，说明还差得远）。

## 梯度只给方向，不给步长

有了梯度，你知道了每个参数该往哪个方向调。但那句更新公式还有个空要填：

```
w ← w - ___ × 梯度
           ↑
        步长是多少？
```

这就是**学习率**。它和梯度是同一句话的两半：**梯度管方向，学习率管走多远**。

那个减号让正负两种情况自动统一：斜率为正（调大就变糟）就减去一个正数，参数变小，走对了；斜率为负（调大反而变好）就减去一个负数等于加上，参数变大，也走对了。

至于步长该取多大——`scripts/step01_gradient_descent.py` 里跑了三组对比（0.1 稳步但慢、0.5 一步到位、1.1 越来越远），那是**训练时怎么调参**的话题，属于第 8 步，现在不用管。（→ 第 8 步）

## 需要数学基础吗？

需要，但**比你以为的少得多**，而且重点在于：**不能先学完数学再开始。**

真正需要的只有这么几个工具，全都是"用到时再补"：

| 工具 | 要掌握到什么程度 | 什么时候用 |
| --- | --- | --- |
| 斜率 / 导数 | 知道"输入变一点，输出变多少" | 现在 |
| 偏导数 | 知道"多个输入时，一次只看一个" | 现在 |
| 矩阵乘法 | 会手算 2×2、清楚形状怎么变 | 第 4 步起每天用 |
| 指数 / softmax | 知道它把任意一串数变成概率 | 第 3 步 |
| 对数 | 知道 log 单调递增、能把乘法变加法 | 第 3 步（交叉熵） |
| 链式法则 | 知道"变化会一层层传下去" | 第 6 步 |

明确**不需要**的：

- 熟练的求导技巧——PyTorch 自动做，你要的是读懂它、判断它对不对
- 线性代数的证明（特征值、秩、正交化）
- 概率论的公理化体系
- 任何"证明"能力

有一个转变值得说清楚：**深度学习把求导自动化了，所以数学的角色从"你会算"变成了"你能解释它为什么这么算"。** 这比手算简单得多——但不能跳过。不理解梯度是什么，训练不收敛时你就无法判断该怪学习率、怪数据，还是怪模型结构。

补数学的原则是：**卡住时补，用最小剂量。** 哪一步的公式看不懂了，只补那一个，十分钟，补到能继续读为止。不要展开成"线性代数 + 微积分 + 概率论"三件套——那是一条准备一辈子都不会开始的经典路径。

唯一的例外就是梯度：它现在就值得弄懂，因为后面每一步都在用它。

## 本文提到的名词

累计索引见 [glossary.md](./glossary.md)。

- **斜率**：函数在某一点的变化率。读法是"输入每增加 1，输出大约变化多少"。**注意它不是函数值**——值回答"现在多高"，斜率回答"往哪走"。
- **导数**：斜率在数学上的正式名字，写作 `d/dw`。
- **偏导数**：多个输入时，一次只对其中一个求斜率，其余当作不动。名字里的"偏"就是这个意思。
- **梯度**：所有参数的偏导数打包成的张量，**形状与参数完全相同**。
- **发散（diverge）**：沿着斜率反方向走时，每步都跨过谷底并且越走越远，损失不降反升。（→ 第 8 步展开）

`损失` 与 `学习率` 在第 0 步讲「超参数」时就提过，本文只是第一次给出够用的定义。术语提前出现是正常的，没登记才是问题，见 [glossary.md](./glossary.md) 的「见过了，但还没讲到」。

## 自测

1. 梯度是"每个参数各有一个斜率"，那么梯度的**形状**和什么一样？
2. 更新参数时为什么用减号而不是加号？
3. 斜率是 `-6` 时，说明把参数调大以后，函数值会变大还是变小？
4. 如果某个参数的梯度算出来是 0，这个参数这一步会怎么样？

## 自测详解

### 1. 梯度的形状和什么一样？

**和参数完全一样。** 每个参数都需要自己的一份"往哪边调"，所以梯度是一个与参数同形状的张量——100 万个参数就有 100 万个斜率。

`step01_grad_demo.py` 的第 2 行印证了这点：`x` 的形状是 `(3,)`，`x.grad` 的形状也是 `(3,)`。到了第 7 步，模型参数有几百万个、分成好几十个不同形状的张量，梯度会一一对应，一个不多一个不少。

### 2. 为什么用减号？

因为减号让两种情况自动统一：

- 斜率为**正** → "把参数调大，损失会变大" → 减去一个正数 → 参数变小 → 走对了。
- 斜率为**负** → "把参数调大，损失反而变小" → 减去一个负数等于加上 → 参数变大 → 也走对了。

写成加号就变成"往损失变大的方向走"，专门用来把结果搞坏。

### 3. 斜率是 `-6` 时，函数值会怎么变？

斜率为负，说明**把参数调大，函数值会变小**。具体地说，参数增加 1，`f` 大约减少 6；增加 0.1，`f` 大约减少 0.6。这就是"变化率"的含义，也是为什么更新时要减一个负数——等于把参数调大。

注意"大约"两个字：斜率本身随位置变化，只在**一小步**内这个估计才准。步子迈大了，估计就失效了，这也正是第 8 步要处理步长的原因。

### 4. 梯度为 0 会怎么样？

这个参数**这一步不动**（`w ← w - 学习率 × 0 = w`）。

在本文这个例子里，`w = 3` 时斜率恰好是 0，因为那正是谷底——这是好事，是收敛的标志。但梯度为 0 也可能是坏事：如果中间某一层的输出全是 0，"变化传不过去"，上游参数收到的梯度也是 0，尽管它离最优还很远。这叫**梯度消失**，是深层网络的真问题。（→ 第 7 步用残差连接正面解决）

区分这两种"梯度为 0"，正是为什么训练时不能只盯一个数字。
