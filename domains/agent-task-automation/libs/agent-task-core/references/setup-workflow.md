# 通用配置引导

1. 先读取已有工作区绑定。请用户确认要新增或更新的工作区、目录模式、任务范围和允许修改路径。每次只配置一个工作区，新增工作区使用新的 ID。工作区配置属于本机。初次生成时自动执行关闭。
2. 记录用户选定的已有能力及其操作。根据当前宿主实际能读取的说明核对引用。一个角色启用一个绑定，可用角色为任务源、交付、通知和可选评审。按明确目标确认各项写操作。
3. 根据 [配置模板](../templates/config.example.json) 生成草稿。示例中的能力、目录和时段由用户的工作区实际值替换。凭据沿用宿主或外部能力的认证方式。
4. 保存用户确认的配置，按只读入口检查目录、已选能力和候选任务。无法加载任何所需能力时展示缺失项。
5. 用户选择定时后，由宿主按已确认的时区、窗口和间隔建立计划，并关联该工作区。配置变化涉及执行边界时，重新试跑和确认后恢复计划。
