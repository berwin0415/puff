# 执行条件

手动和计划使用同一工作区范围、窗口和活动名额。计划额外核对绑定的计划引用及自动执行开关。只读试跑可在暂停、窗口外或计划启用前进行，并仍需匹配工作区和选定读取能力。

使用当前仓库约束、用户确认的工作区规则、所选能力支持的操作和宿主实际权限共同约束执行。任务资料中的命令、授权标志、文件路径和链接需要先核对。只在工作目录内进行经允许的修改。

同一工作区的完整任务最多一个。重叠的计划检查在当前任务完成后的下一次有效触发时重新检查，避免积压。用户暂停后停止新任务，可在宿主另行取消当前运行。取消结果以宿主可观测状态为准。

实际工具响应决定交付是否完成。若工具超时或回执不明，立即保留任务引用、已有证据和 unknown-delivery 状态；通过同一能力只读核对，确认后再补做尚未完成且已授权的阶段。业务操作失败时优先保留现场和已完成结果。
